The reusable GitHub workflows published from runway's
[`lib/github-workflows/`](https://github.com/noisypigeon/runway/tree/main/lib/github-workflows),
one page per version (LIB-0049). GitHub calls a workflow only by its repo
path, so each page gives the exact `uses:` line to copy, with the workflow's
inputs, secrets and outputs at that version.
