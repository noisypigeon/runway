fetches.

## `container-image-release.yml`

```yaml
uses: noisypigeon/runway/.github/workflows/container-image-release.yml@github/workflows/v11.0.0
```

[Source at this tag](https://github.com/noisypigeon/runway/blob/github/workflows/v11.0.0/.github/workflows/container-image-release.yml)

**Inputs**

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `version` | string | yes |  | The version to publish, bare (X.Y.Z). Tagged X.Y.Z and X.Y. |
| `ref` | string | no |  | Git ref to build. Defaults to the tag v&lt;version&gt;. |
| `image` | string | no |  | Image name without a tag. Defaults to ghcr.io/&lt;owner&gt;/&lt;repo&gt;, lowercased. |
| `context` | string | no | `.` | Build context, relative to the caller's repo root. |
| `dockerfile` | string | no | `Dockerfile` | Dockerfile path, relative to the caller's repo root. |
| `platforms` | string | no | `[   { "runner": "ubuntu-24.04-arm", "platform": "linux/arm64" },   { "runner": "ubuntu-24.04", "platform": "linux/amd64" } ]` | JSON array of {"runner": "...", "platform": "linux/&lt;arch&gt;"}, one native build per entry. |
| `build_args` | string | no |  | Newline-separated KEY=VALUE build arguments. |
| `smoke_test` | string | no |  | Shell run inside each platform's image (`sh -ec`, entrypoint overridden) before it is pushed. A non-zero exit fails the release and nothing reaches the registry. Empty skips the check. |
| `latest` | boolean | no | `true` | Also move the `latest` tag to this version. |

**Outputs**

| Name | Description |
| --- | --- |
| `image` | The image name published to. |
| `digest` | The multi-arch index digest. |
