# Decision records have moved

Since [LIB-0056](https://github.com/noisypigeon/runway/blob/67b211c2d7af93f5392dcecc6d619399c42b218a/tools/docs/adr/LIB-0056-decision-records-in-github-discussions.md),
the family's decision records are GitHub Discussions in this repository:

- [**ADR**](https://github.com/noisypigeon/runway/discussions/categories/adr)
  holds new records, from LIB-0057 on.
- [**ADR Archive**](https://github.com/noisypigeon/runway/discussions/categories/adr-archive)
  holds every record that was a file here: LIB-0001 to LIB-0056, and the
  frozen `DEV-` records.

The files as they last stood are at
[`67b211c2d7af93f5392dcecc6d619399c42b218a`](https://github.com/noisypigeon/runway/tree/67b211c2d7af93f5392dcecc6d619399c42b218a/tools/docs/adr).
To find a record by its ID, search the discussions, e.g.
[`LIB-0047 in:title`](https://github.com/noisypigeon/runway/discussions?discussions_q=LIB-0047+in%3Atitle).
`tools/docs/runbooks/file-a-decision-record.md` files, reads and amends them.
